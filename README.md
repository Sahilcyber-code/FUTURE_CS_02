# Phishing Email Detection & Awareness System

## Cyber Security Internship – Task 2

### Future Interns

## Project Overview

This project focuses on phishing email investigation, threat analysis, and cybersecurity awareness. The objective was to analyze multiple phishing-related security alerts, identify indicators of compromise (IOCs), classify phishing risks, and document findings in a professional SOC analyst investigation format.

The project simulates real-world phishing analysis workflows commonly used in Security Operations Centers (SOCs) and cybersecurity teams.

---

# Objectives

* Analyze phishing email samples
* Investigate suspicious domains and URLs
* Identify phishing indicators and social engineering tactics
* Classify phishing threats based on severity
* Perform IOC investigation and documentation
* Create phishing awareness and prevention guidelines
* Improve practical SOC analyst investigation skills

# Investigation Methodology

The investigation process followed a structured SOC-style workflow:

1. Collection of suspicious phishing emails
2. Email content analysis
3. Sender/domain investigation
4. URL and infrastructure analysis
5. IOC identification
6. Risk classification
7. Incident escalation assessment
8. Remediation recommendation documentation

# Prevention & Awareness Recommendations

* Verify sender domains carefully
* Avoid clicking suspicious links
* Enable Multi-Factor Authentication (MFA)
* Report phishing emails immediately
* Avoid sharing passwords or OTPs
* Conduct regular phishing awareness training
* Implement SPF, DKIM, and DMARC policies

# Conclusion

This project demonstrated practical phishing investigation techniques used in modern cybersecurity operations and SOC environments. Multiple phishing scenarios were analyzed to identify malicious indicators, social engineering techniques, and suspicious infrastructure associated with phishing campaigns.
